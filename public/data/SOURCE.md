# Yacht Hydrodynamics data

File `yacht.csv` is a comma-separated conversion of `yacht_hydrodynamics.data` (308 rows; columns a1..a6 are the hull/flow inputs, `y` is the residuary resistance per unit weight of displacement).

- Authors: Gerritsma, J., Onnink, R., Versluis, A.
- Title: *Yacht Hydrodynamics*
- Source: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/243/yacht+hydrodynamics
